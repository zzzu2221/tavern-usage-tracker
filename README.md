# 🍺 酒馆使用追踪器 (Tavern Usage Tracker)

一个 SillyTavern（酒馆）扩展插件，帮你统计每天在酒馆里花了多少时间、敲了多少字，并且 **PC 端和移动端分开计算**。

## ✨ 功能

- **使用时长统计**：自动记录每天使用酒馆的时长
- **PC / 移动端分开**：根据设备自动识别，分别统计
- **输入字数统计**：统计每天发送的消息总字数
- **最近 7 天趋势**：表格展示近一周的使用情况
- **累计统计**：总时长、总字数、活跃天数
- **智能暂停**：
  - 切到后台 / 最小化浏览器 → 自动暂停计时
  - 5 分钟无操作 → 自动暂停（可配置）
  - 回来后自动恢复

## 📦 安装

### 方法一：手动安装（推荐）

1. 下载本插件文件夹 `tavern-usage-tracker`
2. 将整个文件夹复制到酒馆的扩展目录：
   - **Windows**：`SillyTavern\public\scripts\extensions\third-party\`
   - 或者：`SillyTavern\data\<你的用户名>\extensions\`
3. 重启酒馆（或刷新页面）
4. 在「扩展管理」中确认「酒馆使用追踪器」已启用

### 方法二：通过 GitHub 安装

如果把这个文件夹推到 GitHub 仓库，可以在酒馆的「扩展」→「安装扩展」中粘贴仓库地址，一键安装。

## 🚀 使用

安装完成后，在酒馆的输入框中输入斜杠命令：

```
/usage
```

即可弹出统计面板，查看：
- 今日 PC / 移动端使用时长和输入字数
- 最近 7 天详细数据
- 累计总时长、总字数、活跃天数

别名命令：`/统计`、`/使用时长` 也可以打开面板。

## ⚙️ 配置

如果你想修改**空闲超时时间**（默认 5 分钟无操作暂停计时），可以在浏览器控制台执行：

```javascript
// 例如改为 10 分钟（600秒）
SillyTavern.getContext().extensionSettings['tavern_usage_tracker'].idleTimeout = 600;
SillyTavern.getContext().saveSettingsDebounced();
```

## 📊 数据说明

| 指标 | 说明 |
|------|------|
| 使用时长 | 页面活跃且有操作时累计，单位秒 |
| 输入字数 | 按发送的消息文本长度统计（含标点、空格） |
| PC 端 | 通过 User Agent + 屏幕尺寸识别为桌面设备 |
| 移动端 | 识别为手机 / 平板设备 |

> **注意**：编辑或删除已发送的消息不会改变字数统计，字数只在发送时计入。

## 🔧 技术原理

- **时长统计**：每秒检查一次页面状态，活跃则累加 1 秒
- **活跃判定**：页面可见 + 窗口聚焦 + 最近 N 秒内有操作（鼠标/键盘/触摸）
- **设备识别**：`navigator.userAgent` 匹配移动端特征 + 触屏/屏幕宽度辅助判断
- **字数统计**：监听 `MESSAGE_SENT` 事件，读取消息文本长度
- **数据持久化**：使用 SillyTavern 官方 `extensionSettings` API，自动保存到服务器
