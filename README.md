# 🍺 酒馆使用追踪器 (Tavern Usage Tracker)

一个 SillyTavern（酒馆）扩展插件，帮你统计每天在酒馆里花了多少时间、敲了多少字，并且 **PC 端和移动端分开计算**。

## ✨ 功能

### 📊 统计功能
- **使用时长统计**：自动记录每天使用酒馆的时长
- **PC / 移动端分开**：根据设备自动识别，分别统计
- **输入字数统计**：统计每天发送的消息总字数
- **最近 7 天趋势**：柱状图 + 表格展示近一周的使用情况
- **累计统计**：总时长、总字数、活跃天数

### 🖱️ 交互方式
- **悬浮按钮**：右下角常驻圆形 🍺 按钮，点击打开统计面板
  - 可拖动到任意位置，位置自动保存
  - 活跃时呼吸动画效果
  - 移动端默认在屏幕右侧 60% 高度，不挡输入框
- **斜杠命令**：`/usage`、`/统计`、`/使用时长`
- **扩展设置面板**：在「扩展管理」里可以控制所有开关

### ⚙️ 可配置项
- **启用扩展总开关**：一键开关所有功能
- **悬浮按钮开关**：显示/隐藏悬浮按钮
- **空闲超时时间**：1-120 分钟无操作自动暂停计时
- **查看统计**：一键打开统计面板
- **重置今日数据**：清空今天的时长和字数

### 🧠 智能暂停
- 切到后台 / 最小化浏览器 → 自动暂停计时
- 无操作超过设定时间 → 自动暂停
- 回来后自动恢复

## 📦 安装

### 方法一：通过 GitHub 安装（推荐）

1. 打开酒馆 → 「扩展」→「安装扩展」
2. 粘贴仓库地址：`https://github.com/zzzu2221/tavern-usage-tracker`
3. 点击安装，重启酒馆
4. 在「扩展管理」中确认「酒馆使用追踪器」已启用

### 方法二：手动安装

1. 下载本插件文件夹 `tavern-usage-tracker`
2. 将整个文件夹复制到酒馆的扩展目录：
   - **Windows**：`SillyTavern\public\scripts\extensions\third-party\`
3. 重启酒馆（或刷新页面）

## 🚀 使用

安装完成后：

1. **点击右下角悬浮 🍺 按钮** → 打开统计面板
2. 或者在输入框输入 `/usage` → 也可以打开

统计面板包含：
- 今日统计卡片（PC端、移动端、合计）
- 最近 7 天时长趋势柱状图
- 最近 7 天详细数据表格
- 累计统计（总时长、总字数、活跃天数）

## ⚙️ 设置

在酒馆顶部「扩展程序」→「管理扩展程序」→「酒馆使用追踪器」面板中可以配置：

| 设置项 | 说明 |
|--------|------|
| 启用扩展 | 总开关，关闭后停止所有统计 |
| 显示悬浮按钮 | 控制右下角 🍺 按钮的显示/隐藏 |
| 空闲超时 | 无操作多少分钟后自动暂停计时 |
| 查看使用统计 | 一键打开统计面板 |
| 重置今日数据 | 清空今天的时长和字数 |

## 📊 数据说明

| 指标 | 说明 |
|------|------|
| 使用时长 | 页面活跃且有操作时累计，单位秒 |
| 输入字数 | 按发送的消息文本长度统计（含标点、空格） |
| PC 端 | 通过 User Agent + 触屏 + 屏幕宽度识别 |
| 移动端 | 识别为手机 / 平板设备 |

> **注意**：编辑或删除已发送的消息不会改变字数统计，字数只在发送时计入。

## 🔧 技术原理

- **时长统计**：每秒检查一次页面状态，活跃则累加 1 秒
- **活跃判定**：页面可见 + 窗口聚焦 + 最近 N 秒内有操作
- **设备识别**：User Agent 匹配移动端特征 + 触屏 + 屏幕宽度
- **字数统计**：监听发送按钮点击 + Enter 键 + MESSAGE_SENT 事件
- **悬浮按钮**：圆形设计，pointer 事件统一处理拖动和点击
- **数据持久化**：使用 SillyTavern 官方 `extensionSettings` API，自动保存到服务器
